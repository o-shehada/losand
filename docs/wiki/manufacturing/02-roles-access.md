## الصلاحيات

يحتاج كل مستخدم إلى حساب Frappe/ERPNext، ودور مناسب، وتعيين صريح في محطة عمل واحدة على الأقل.

| الدور | إدخال البيانات | ترحيل المخزون |
|---|---:|---:|
| System Manager | نعم | نعم |
| Manufacturing Manager | نعم | نعم |
| Manufacture Supervisor | نعم | نعم |
| Manufacturing User | نعم | لا |
| Manufacture Operator | نعم | لا |
| Stock User | نعم | لا |

الترحيل النهائي لا يعتمد على ظهور الزر فقط؛ يعيد الخادم فحص الدور لحظة الضغط على **تأكيد وترحيل الدفعة**.

## تعيين المستخدم إلى محطة عمل

1. افتح **Workbench** من Desk.
2. افتح محطة العمل المطلوبة.
3. في جدول **System Users** أضف المستخدم وحدد ورديته.
4. احفظ السجل.

لن تظهر للمستخدم إلا المحطات المفعّلة التي أُضيف إليها في جدول **System Users**. تعطيل محطة العمل يخفيها عن الجميع.

![سجل Workbench يظهر جدول System Users وحقل Shift](/files/02-workbench-users-shift.png)

يمكن إضافة عامل غير مستخدم للنظام في جدول **Workers (non-system)** لأغراض التنظيم. هذا لا يمنحه حساب دخول أو صلاحية ترحيل.

## كيف تُبنى قائمة الورديات؟

يعرض النظام الورديات الموجودة في صفوف المستخدمين والعمال للمحطة. إذا لم توجد أي وردية مرتبطة بالمحطة، يعرض جميع سجلات **Shift** المتاحة.

## منح الصلاحية بطريقة صحيحة

- المشغّل الذي يسجل فقط: `Manufacture Operator` أو `Manufacturing User` مع تعيينه للمحطة.
- المشرف الذي يرحّل: `Manufacture Supervisor` مع تعيينه للمحطة.
- مدير الإعدادات: `Manufacturing Manager`.
- لا تمنح `System Manager` لمجرد الحاجة إلى الترحيل؛ هذا الدور أوسع بكثير من نظام التصنيع.

## رسائل الوصول الشائعة

**لا توجد محطات عمل معرّفة:** غالبًا المستخدم غير مضاف إلى أي محطة، أو المحطة معطلة.

**ليس لديك صلاحية ترحيل الإنتاج:** المستخدم يستطيع المراجعة لكنه لا يحمل أحد أدوار الترحيل.

**You are not assigned to this workbench:** تغير تعيين المستخدم أو حاول إرسال بيانات لمحطة غير مسموحة.

**إعادة تسجيل الدخول:** بعد تعديل الأدوار، سجّل الخروج ثم الدخول لتحديث الجلسة. النظام يعيد فحص الصلاحية أيضًا قبل الترحيل.
