## قائمة المشغّل قبل الترحيل

- [ ] المحطة والوردية صحيحتان.
- [ ] جميع الكميات بوحدة الصنف الظاهرة.
- [ ] المواد المستهلكة تعكس الاستهلاك الفعلي.
- [ ] الفاقد مسجل منفصلًا ولا يتكرر ضمن المستهلك.
- [ ] مجموع المستهلك والفاقد لا يتجاوز المتاح.
- [ ] كميات وأوزان المنتجات النهائية منطقية.
- [ ] الملاحظات التشغيلية المهمة مسجلة.
- [ ] الملخص تمت مراجعته قبل الضغط على الترحيل.

## قائمة المشرف بعد الترحيل

- [ ] ظهرت صفحة النجاح.
- [ ] يوجد رقم دفعة `LAB-#####`.
- [ ] ظهرت أرقام النقل والصرف والاستلام.
- [ ] حالة الدفعة `Completed`.
- [ ] لا يوجد رصيد غير مفسر في WIP.
- [ ] أي فرق تكلفة أو فاقد غير طبيعي تم توثيقه.

## قائمة مدير النظام عند إنشاء محطة

- [ ] الشركة وحساب Production Clearing صحيحان.
- [ ] المخازن الثلاثة موجودة وتابعة للشركة الصحيحة.
- [ ] الفئة موجودة.
- [ ] المواد الخام معرفة ووحداتها صحيحة.
- [ ] المنتجات النهائية لها فئة ووزن ومواد خام.
- [ ] إعدادات التشغيلات والعمر التخزيني صحيحة.
- [ ] الوردية موجودة.
- [ ] المستخدمون وأدوارهم وتعييناتهم صحيحة.
- [ ] تم إدخال مخزون اختبار صالح.
- [ ] نُفذت دفعة اختبار ومراجعة الحركات الثلاث.

## قواعد تشغيلية مختصرة

1. سجّل الواقع، لا الوصفة النظرية.
2. لا تخلط وحدات القياس.
3. الفاقد جزء من الخصم والتكلفة.
4. لا تُعد إرسال دفعة فاشلة قبل فحص حركاتها.
5. لا تُلغِ حركة مخزون واحدة منفردة.
6. رقم `LAB` هو مرجع الدعم والتدقيق.
7. التكلفة النهائية هي تكلفة ERPNext بعد الصرف، لا مجرد المعاينة.
8. راجع التشغيلات وتواريخ الانتهاء دوريًا لضمان FEFO.

## قاموس الحقول

| الحقل | الاستخدام |
|---|---|
| Product Category | يجمع المنتجات النهائية التي تظهر في محطة واحدة. |
| Is Raw Material | يجعل الصنف متاحًا للاختيار كمادة خام. |
| Is Final Product | يجعل الصنف يظهر كمنتج نهائي. |
| Raw Materials | يربط المنتج النهائي بمواده الممكنة. |
| Weight Per Unit | وزن القطعة المستخدم لتوزيع التكلفة. |
| Raw Material Warehouse | مصدر المواد قبل الإنتاج. |
| Manufacturing Warehouse | مخزن WIP الوسيط. |
| Finished Goods Warehouse | وجهة المنتجات المكتملة. |
| Production Clearing Account | حساب مقابل للصرف والاستلام. |
| Batch Reference | مرجع مؤقت يظهر أثناء الإدخال. |
| Production Batch | سجل التدقيق الدائم ورقمه LAB. |
